
## 硬件与运行环境

| 项目    | 当前实测配置                                                                                                             |
| ----- | ------------------------------------------------------------------------------------------------------------------ |
| 相机    | RealSense D430 模组 + D4 处理板；使用双目红外流（`infra1` / `infra2`，**848×480 @ 30 Hz**，关闭结构光 `emitter_enabled:=0`），不使用相机内置 IMU |
| 飞控与固件 | MicoAir743v2-AIO-35A（STM32H7，固件目标 `micoair_h743-v2_default`，PX4 v1.16.2，已解除 DDS `SensorCombined` 限频）               |
| 机载电脑  | Orange Pi（全志 A733，2×A76 + 6×A55，6 GB RAM，Ubuntu 22.04 arm64，ROS 2 Humble），局域网 `ssh orangepi@192.168.5.109`         |
| 飞控通信  | 香橙派 `/dev/ttyS7` 对接飞控 `TELEM2`（`ttyS3`），波特率 `1500000`，Micro-XRCE-DDS Agent                                         |
| 坐标系约定 | PX4 IMU 桥接输出 `/imu` 为 **FRD**（`use_flu_frame: false`）；OpenVINS 全局系 `global` 为 **FLU（Z 轴向上）**，机体系 `imu` 为 **FRD**   |
