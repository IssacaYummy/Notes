# 更改中文和中文输入法

## 1. 更改中文

先安装中文语言包和中文字体：

```bash
sudo apt update
sudo apt install language-pack-zh-hans language-pack-zh-hans-base \
  language-pack-gnome-zh-hans language-pack-gnome-zh-hans-base \
  fonts-noto-cjk
```

然后生成并设置中文 Locale：

```bash
sudo locale-gen zh_CN.UTF-8
sudo update-locale LANG=zh_CN.UTF-8 LANGUAGE="zh_CN:zh:en_US:en"
```

注销当前 XFCE 会话并重新登录。重新登录后，菜单、文件管理器、设置等大部分界面应该变成中文。

如果想通过图形界面设置，也可以运行：

```
gnome-language-selector
```

如果提示命令不存在：

```
sudo apt install language-selector-gnome
```

打开后选择“汉语（中国）/ Chinese (China)”，然后重新登录。

重新登陆后一定要选择保留旧的文件目录名称，因为英文更方便

## 2. 更改中文输入法

中文输入法推荐 Fcitx5。安装：

```bash
sudo apt install fcitx5 fcitx5-chinese-addons fcitx5-config-qt \
  fcitx5-frontend-gtk3 fcitx5-frontend-qt5
```

然后让系统使用 Fcitx5：

```bash
im-config -n fcitx5
```

建议再配置 XFCE 会话环境。在 `~/.xprofile` 中加入：

```bash
cat >> ~/.xprofile <<'EOF'
export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx
EOF
```

之后注销并重新登录。

登录后运行：

```bash
fcitx5-configtool
```

在“输入法”中添加：

```
拼音 / Pinyin
```

# 安装并使用ssh
## 1. 在被远程的电脑上开启ssh

```bash
sudo apt update
sudo apt install openssh-server tmux
sudo ssh-keygen -A
sudo systemctl enable --now ssh
systemctl status ssh --no-pager
```
![[PixPin_2026-10-24_09-49-55.webp]]

看到 `active (running)`，表示 SSH 服务已启动

查看当前用户名和 IP 
```bash
whoami
hostname -I
```

检查防火墙并放行
```bash
sudo ufw status
sudo ufw allow OpenSSH
```

确认你和被远程的电脑在同一个局域网，以OrangePi为例

## 免密登陆远程设备

首先查看本地有没有ssh-key

```bash
# 检查本地是否已有公钥
ls ~/.ssh/id_*.pub
```

如果没有的话就执行命令生成，可以一直按回车保持默认，有的话跳过这一步

```bash
ssh-keygen -t ed25519
```

将该电脑的公钥追加到被远程的电脑

```bash
ssh-copy-id 用户名@机载IP
```

然后可以使用下面的命令免密登陆

```bash
ssh "用户名@机载IP"
```

## 使用scp
### 1. 复制单个文件到本地

```bash
scp username@remote_host:/path/to/remote/file.txt /path/to/local/dir/
```

### 2. 复制整个文件夹到本地

```bash
scp -r username@remote_host:/path/to/remote/folder /path/to/local/dir/
```
### 3. 上传单个文件

上传制定文件

```bash
scp /path/to/local/file.txt username@remote_host:/path/to/remote/dir/
```

**上传当前目录下的文件**：

```bash
scp file.txt username@remote_host:/home/username/
```
### 4. 上传整个文件夹（使用 `-r` 递归）

```bash
scp -r /path/to/local/folder username@remote_host:/path/to/remote/dir/
```

## 使用 `rsync`

对于大文件、大量文件或不稳定的网络连接，`rsync` 远优于 `scp`。

### 1. 复制单个文件到本地

```bash
rsync -avzP username@remote_host:/path/to/remote/file.txt /path/to/local/dir/
```

### 2. 复制文件夹到本地

```bash
rsync -avzP username@remote_host:/path/to/remote/folder /path/to/local/dir/

rsync -avzP orangepi@192.168.5.109:/home/orangepi/bags/ /home/yummy/UAV_NAV/data/bags/test-bags/raw_data/
```

### 3. 上传单个文件

```bash
rsync -avzP /path/to/local/file.txt username@remote_host:/path/to/remote/dir/
```

### 4. 上传文件夹

```bash
rsync -avzP /path/to/local/folder username@remote_host:/path/to/remote/dir/
```

 **注意末尾斜杠 `/` 的区别**：
 - `folder`（不带斜杠）：会在本地目标路径下创建名为 `folder` 的文件夹。
- `folder/`（带斜杠）：只会把该目录下的**所有内容**复制过去，不会在本地多套一层 `folder` 目录名。     

常用选项说明
- `-a`：归档模式，保留文件权限、属主、修改时间、软链接等属性。
- `-v`：输出详细传输日志（verbose）。  
- `-z`：传输时启用压缩，加速网络传输。
- `-P`：包含 `--progress`（显示进度条）和 `--partial`（保留断点文件，支持**断点续传**
