## 1. 核心目标与无歧义规则边界

### 1.1 系统构成与通信约束

- **系统规模**：由 **4 台微型无人机 + 1 座地面机库** 组成完整作战/竞赛单元。
    
- **物理限制**：
    
    - **无人机**：投影尺寸与整机重量受耦合限制，二者呈线性反比约束（规则边界为：质量上限 $249\text{ g}$ 对应尺寸 $60\text{ mm}$，尺寸上限 $141\text{ mm}$ 对应质量 $150\text{ g}$）。
        
    - **机库**：仅受外形尺寸限制，无重量硬性红线。
        
- **起飞与通信机制**：无人机初始停放于机库内部并从机库起飞；无人机必须接收到机库下发的指令后方可解锁起飞，因此**无人机与机库之间必须具备可靠的指令通信链路**（通信体制待定）。无人机只能在机库内与机库进行近场无线通信，比赛中不允许使用包括wifi 蓝牙等在内的无线通信，不允许使用光纤

### 1.2 全自主与能源边界

- **运行模式**：比赛全程 **100% 全自主运行**（无人工遥控介入）。
    
- **能源与航时约束**：单机允许携带的锂电池最大额定能量为 **$4\text{ Wh}$**。单次起飞续航直接受 $4\text{ Wh}$ 能量池限制，比赛全程起飞架次暂不设固定上限。
    
- **多次出动与自动换电愿景**：目标架构要求无人机在完成撞击任务后能够自主返回机库，由机库内部的**自动换电机构**更换满电电池以执行多轮次出动；该机制的先决条件是无人机端与电池端具备**易插拔、耐振动、大电流的快拆电池接口**（方案调研中）。

### 1.3 唯一任务功能：装甲模块有效撞击

无人机在赛场上的唯一任务是对目标执行物理**撞击**，目标与判定机理定义如下：

- **目标对象（装甲模块）**：表面集成了点阵屏幕、具备明确视觉特征的打击目标。
    
- **装甲支撑架几何参数（依据图 3-15，比例 1:2）**：
    
    - 正面外廓尺寸：总宽 $141\text{ mm}$、总高 $133\text{ mm}$，顶部双凸耳内间距 $70.9\text{ mm}$。
        
    - 侧面倾角与尺寸：倾斜装甲安装面长度 $125\text{ mm}$，装甲面与底部水平基准面夹角为 $112^\circ$（即相对铅垂面倾斜 $22^\circ$），下部台阶高度 $40\text{ mm}$。
        
    - 机械安装接口：背面含 $4\text{-M4}$ 螺纹孔（竖向孔距 $30\text{ mm}$、下孔距底边 $18\text{ mm}$、支架条宽 $15\text{ mm}$），顶/底面含 $2\text{-M4}$ 通孔与 $2\text{-M4}$ 深度 $10\text{ mm}$ 螺纹孔（横向孔距 $86\text{ mm}$、进深 $33.5\text{ mm}$）。
        
- **有效撞击判定机理（依据“空中机器人冲击”规则说明）**：
    
    - **冲击事件定义**：当装甲模块检测面任意位置检测到接触力高于阈值 $\alpha\text{ N}$ 时，开启一次“冲击事件”；此后当所有位置接触力均低于 $\alpha\text{ N}$ 时，该次“冲击事件”结束。
        
    - **接触时间**：即单次“冲击事件”的持续时间（合格区间待定）。
        
    - **冲击面积 $S$**：整个“冲击事件”内所有即时接触力大于 $\alpha\text{ N}$ 的区域面积之和，区域允许不连续。
        
    - **面累积冲量**：定义为冲击面积上的接触力对接触时间与冲击面积的二重积分（合格区间待定）：
        $$I_{\text{area}} = \iint F \, dt \, dS$$
        
    - **工程推论（供控制与结构协同参考）**：由于判定指标同时受接触力 $F$、持续时间 $dt$ 与有效触碰面积 $S$ 三者乘积耦合影响，单纯追求“高刚度点接触弹飞”未必最优，需在**撞击末速度、机体质量、前向接触面几何与缓冲弹性**之间联合优化。

### 1.4 场地先验条件

- **已知环境**：比赛场地空间布局完全已知，且官方提供场地 **STL 三维模型文件**，可直接用于离线仿真环境搭建与先验地图构建。
    

## 2. 长期目标（Long-Term Vision）

1. **单机端到端任务闭环**：实现“机库指令触发 $\rightarrow$ 机库内无触碰全自主起飞 $\rightarrow$ 无 GNSS 室内导航避障 $\rightarrow$ 视觉识别装甲模块 $\rightarrow$ 高动态精准有效撞击 $\rightarrow$ 撞后姿态与定位恢复 $\rightarrow$ 自主返航精准降落入库”的完整单机能力。
    
2. **多机与机库持续作战闭环**：支持最多 4 台微型机协同调度或分批接力出动，结合机库自动换电机构，突破单块 $4\text{ Wh}$ 电池的航时瓶颈，实现高频率、多轮次的有效撞击输出。
    
3. **算法范式进阶与个人理论沉淀**：在夯实传统模块化导航控制基线（VIO + 建图 + 优化规划 + 串级控制）的基础上，结合《深度学习》等底层理论学习，探索并验证**仿真驱动的强化学习（RL）决策/末制导与端到端避障**在微型高机动平台上的落地边界。
    

## 3. 当前状况与现有基线方案（Current Status & Baseline）

### 3.1 硬件平台现状

核心航电架构目前保持一致（后续可能随轻量化与算力需求演进），已制造出两种符合不同尺寸-重量配比的样机，并配有一台专用测试验证机：

|**机体型号/用途**|**俯视尺寸**|**整机质量**|**电池规格**|**对应动力/结构特征**|**当前定位**|
|---|---|---|---|---|---|
|**样机 A（大桨轻量化构型）**|$132\text{ mm} \times 132\text{ mm}$|$160\text{ g}$|3S 340mAh|对应 1104 7200KV + 2.2 寸三叶桨路线（规则上限约 $160.8\text{ g}$）|规则合规原型机|
|**样机 B（紧凑重载构型）**|$100\text{ mm} \times 100\text{ mm}$|$200\text{ g}$|2S 500mAh|对应致盈 1003 14000KV + GF 1609R*4 四叶桨路线（50% 油门单轴推力 $65\text{ g}$、力效 $3.819\text{ g/W}$）|规则合规原型机|
|**现役测试验证机**|$132\text{ mm} \times 132\text{ mm}$|$249\text{ g}$|3S 580mAh|续航时间待测；用于当前算法上机验证与调试|**主力算法测试平台**|

- **核心航电与传感器基线（可能迭代）**：
    
    - **飞控**：微空 MicoAir743v2-AIO-35A（STM32H743，集成 35A 四合一电调，支持 2S~6S，运行 PX4 v1.16.2，`micoair_h743-v2_default`）。
        
    - **机载算力板**：Orange Pi 全志 A733 平台（2×Cortex-A76 + 6×Cortex-A55 + 独立 NPU，6GB RAM，Ubuntu 22.04 arm64 + ROS 2 Humble）。
        
    - **定位与深度传感器**：去外壳轻量化 Intel RealSense D430 双目模组 + D4 处理板（全局快门红外双目，物理基线 $50\text{ mm}$，USB 3.0 接入，运行时关闭中间红外结构光发射器）。
        
    - **目标识别传感器（规划中基线）**：原生 MIPI CSI 接口 IMX219 彩色摄像头（约 $3\text{ g}$，拟中置贴装于 D430 中央闲置红外发射窗前方）。

### 3.2 已验证的软件与控制导航基线

- **通信链路**：飞控 TELEM2 与算力板通过 1.5 Mbps 串口运行 uXRCE-DDS，IMU 内部积分 400 Hz、DDS 发布 200 Hz，并通过 `taskset` 实现大小核资源隔离。
    
- **标定体系**：
    
    - 使用 Kalibr 工具链完成双目内参及相机-IMU 时空联合标定；**当前标定板已正式切换为 AprilTag（AprilGrid）**，替代早期棋盘格方案。
        
    - 已验证的关键物理特性：D430 实测基线 $50.01\text{ mm}$、重投影误差 $0.068\text{ px}$、串口软同步时间偏移约 $62.3\text{ ms}$；同时识别出早期测试架上 D430 相对飞控存在绕前向轴 $180^\circ$ 倒置安装特征。
        
    - 明确 7 分钟级短航时微型机无需耗费数十小时测静态 Allan 方差，飞行阶段采用针对高频电机振动放宽的经验 IMU 噪声参数。
        
- **状态估计（VIO）**：采用 **OpenVINS**（Hybrid MSCKF + SLAM，开启 FEJ、在线外参/时延校准、关闭 `wait_for_jerk` 实现地面静置 1 秒纯静态初始化）。
    
- **飞控融合与自主起降**：
    
    - PX4 EKF2 启用外部视觉融合并将视觉高度设为全局主高度源（`EKF2_HGT_REF=3`、`EKF2_BARO_CTRL=0`），屏蔽下洗气流对气压计的干扰。
        
    - 已验证自定义 `px4_bridge`（ENU/FLU $\leftrightarrow$ NED/FRD 映射）与 `offboard_mission_node` 状态机，打通室内无 GPS 全自主解锁、斜坡爬升、定点悬停与触地自动锁桨降落。
        
- **调试与日志工具链**：采用内存盘 `/dev/shm` 录制 ROS 2 `.mcap` 包避免存储卡 I/O 丢帧，配合 PX4 `.ulg` 日志、PlotJuggler、RViz2、`evo` 及 Rerun 进行轨迹与融合诊断。

### 3.3 当前正在推进的基线环节

- 将 D430 硬件解算的降采样稠密深度图（$424 \times 240$）与 OpenVINS 位姿接入 ROS 2 版 **EGO-Planner**，完成 `grid_map` 局部建图、B 样条局部避障规划，以及 `traj_server`（`/position_cmd`）到 `offboard_mission_node` 的前馈控制闭环联调。

## 5. 开放性研究议题与 AI 协作探讨清单（Divergent Thinking）

以下记录当前尚未形成定论的核心思考，欢迎任何 AI Agent 针对任意条目展开深度推演、提出反直觉视角或设计最小验证实验：


1. **EGO-Planner 跑通之后的下一步是什么？**
    
    - 当无人机实现了基础的稠密建图、局部路径规划与自主避障飞行后，核心矛盾将从“如何不撞”**转变为**“如何精准、高速、可控地撞击指定装甲模块，并在撞击后全身而退”。
        
    - _待探讨_：规划层如何区分“必须避让的障碍物”与“必须穿透接触的装甲目标”？是否需要引入两套独立的运动原语（巡航安全模式 vs 末端加速冲击模式）？
        
2. **双目相机如何安装布局才能使 VIO 与任务综合效果最优？**
    
    - _待探讨_：考虑前向加速俯仰倾角、装甲面 $112^\circ$ 上仰倾角、室内地面与墙面纹理分布、撞击瞬间的镜头物理防护，以及是否保留当前 $180^\circ$ 倒置安装，双目相机应采用水平前视、微俯角还是微仰角安装？基线方向与安装减振该如何权衡？
        
3. **VIO 的鲁棒性边界：撞击瞬间与撞后如何不漂移、不发散？**
    
    - _待探讨_：物理撞击会产生远超量程的高频加速度尖峰（IMU 饱和）、角速度突变与图像剧烈模糊。OpenVINS 在这种非高斯冲击下会发生什么？有哪些工程手段（如撞前冻结状态、加速度计饱和剔除、纯视觉 PnP/AprilTag 重定位、结合官方 STL 场地先验特征拉回）可以抑制漂移，保证飞机撞完还能准确找回机库？
        
4. **如何最大化利用“官方已知场地 STL”的先验红利？**
    
    - _待探讨_：既然赛场几何结构完全已知，离线将 STL 转化为静态占据地图/ESDF 或拓扑路网，能否大幅释放 A733 的在线建图算力，甚至辅助 VIO 进行全局漂移校正？
        
5. **换电机构与快拆电池接口的机电协同设计**
    
    - _待探讨_：在 $100\text{ mm}$–$132\text{ mm}$ 极小机身上，怎样的电池接口才能同时满足“机库机械手低精度易插拔”、“飞行及撞击瞬间绝对不松脱断电”、“承载 30A+ 峰值电流不发热”与“极致轻量化”四重矛盾？
        
6. **下一步的相机、运算平台与整机架构该如何演进？**
    
    - _待探讨_：对比 `132mm / 160g / 3S` 与 `100mm / 200g / 2S` 两条物理路线，结合 $4\text{ Wh}$ 电池约束与撞击面累积冲量公式 $\iint F \, dt \, dS$，“更重但推重比略低的小机身”还是“更轻但加速更快的大机身”更容易触发有效冲击事件？航电与传感器应如何围绕最优构型做减法？
        
7. **仿真环境搭建方案：Gazebo + ROS 2 + PX4（及多仿真器协同）**
